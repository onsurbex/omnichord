# Logotipo original

El recurso de marca debe guardarse como `Assets/BlinblinLogo.png`.
CMake lo incrusta en el VST3 y en la aplicación standalone al compilar.
La interfaz lo muestra automáticamente, respetando proporción y transparencia,
sin depender de un archivo en el ordenador del músico.

El PNG original del usuario todavía no está disponible en este entorno:
el proxy bloquea la descarga desde el enlace de Postimages proporcionado.
No se incluye una reproducción ni una imagen de sustitución.
